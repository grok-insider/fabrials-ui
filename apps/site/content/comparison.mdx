## Usage

Use stable column IDs as keys in each row’s `values`. Values, visuals and actions accept React nodes, so the same component can compare plans, products or settings.

```tsx
import { Comparison } from "@/components/webmcp/comparison";

<Comparison
  caption="Plan features"
  columns={[
    { id: "personal", title: "Personal" },
    { id: "team", title: "Team" },
  ]}
  rows={[
    {
      id: "members",
      label: "Members",
      values: { personal: "1", team: "10" },
      highlighted: true,
    },
  ]}
/>;
```

## Composing a complete flow

Comparison renders the evidence. Your application owns selection, recommendation rules and any side effects. It does not register tools or change application state by itself.

The [shopping example](/playground#comparison) combines Comparison with WebMCP tools, a compatible accessory, shared cart state and human review. For a different use case, see the [project explorer](/playground#explorer) or [reservation flow](/playground#reservation).
